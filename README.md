For more information, please visit our page: [enhancer.at](https://enhancer.at)

## Development

1.  `bun install`
2.  `bun run build` / `bun run dev`
3.  Add `dist` directory as an unpacked extension in your browser.
4.  Refresh the extension in your browser.
