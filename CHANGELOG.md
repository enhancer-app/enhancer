# Changelog

## 5.4.0

### Minor Changes

- Add a Group messages setting (Chat → Messages) that hides the name and badges on consecutive messages from the same user. ([#314](https://github.com/enhancer-app/enhancer/pull/314) by [@igorovh](https://github.com/igorovh))
- Twitch: Add a Join and leave messages setting (Chat → Messages) that shows who joined or left the chat. ([#318](https://github.com/enhancer-app/enhancer/pull/318) by [@igorovh](https://github.com/igorovh))
- Show a short welcome tour once after the first install. ([#315](https://github.com/enhancer-app/enhancer/pull/315) by [@igorovh](https://github.com/igorovh))
- Show a dot on the settings button and a notice in settings when a new Enhancer version has release notes. ([#323](https://github.com/enhancer-app/enhancer/pull/323) by [@igorovh](https://github.com/igorovh))
- Show image previews for prntscr.com links in chat. ([#309](https://github.com/enhancer-app/enhancer/pull/309) by [@igorovh](https://github.com/igorovh))
- Show the real username in a tooltip when you hover a custom Enhancer nickname in chat. ([#321](https://github.com/enhancer-app/enhancer/pull/321) by [@igorovh](https://github.com/igorovh))

### Patch Changes

- Encrypt the saved copy of your Enhancer Account profile and delete it as soon as you log out. ([#319](https://github.com/enhancer-app/enhancer/pull/319) by [@igorovh](https://github.com/igorovh))
- Use spacing and commas instead of middle dots in the Enhancer Account screens and the nickname hint. ([#324](https://github.com/enhancer-app/enhancer/pull/324) by [@igorovh](https://github.com/igorovh))
- Twitch: Hide the chatters counter on clips and VODs. ([#313](https://github.com/enhancer-app/enhancer/pull/313) by [@igorovh](https://github.com/igorovh))
- Enhancer Account: Show the account name only after the profile loads, instead of a technical twitch-<id> name right after logging in. ([#320](https://github.com/enhancer-app/enhancer/pull/320) by [@igorovh](https://github.com/igorovh))
- Show only the Enhancer hover card for multistream channels in the Twitch sidebar and for Similar Channels on Kick. ([#325](https://github.com/enhancer-app/enhancer/pull/325) by [@igorovh](https://github.com/igorovh))
- Load pages faster by rendering the settings panel on first open, and stop tooltips from polling every frame. ([#311](https://github.com/enhancer-app/enhancer/pull/311) by [@igorovh](https://github.com/igorovh))
- Stop losing settings when two changes are saved at once, report failed backups, and stop clearing data from bringing back follows. ([#310](https://github.com/enhancer-app/enhancer/pull/310) by [@igorovh](https://github.com/igorovh))
- Describe the extension more clearly in the browser stores. ([#326](https://github.com/enhancer-app/enhancer/pull/326) by [@igorovh](https://github.com/igorovh))
